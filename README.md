# 设计秘书手机版

这是只在手机上使用的版本。

## 使用方式

把 `mobile` 文件夹发布到任意静态网站空间后，用 iPhone Safari 打开 `index.html` 对应的网址，然后选择“添加到主屏幕”。

## 当前特性

- 手机优先界面
- 快速文字记录
- 支持浏览器语音识别时可语音输入
- 自动识别客户、项目、里程、垫付款和待办
- 拍照/上传图片或 PDF
- 本月里程、待收垫付款、待办统计
- 数据导出备份

## 重要限制

- 数据保存在当前手机浏览器里。
- 不登录、不上传服务器、不跨手机同步。
- 清理 Safari 网站数据可能会删除记录。
- 需要跨手机、换手机、多人协作时，应升级到云端数据库版本。
